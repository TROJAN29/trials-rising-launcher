# Trials Rising Launcher

Unofficial Windows launcher for when **Trials Rising** will not start through Steam or Ubisoft Connect. It may help; it is not guaranteed.

**[Download `TrialsRisingLauncher.exe`](https://github.com/TROJAN29/trials-rising-launcher/releases/tag/workaround)**

1. Open the EXE. It finds your game folder, or use **Browse**.
2. Click **Launch game** and approve the administrator prompt.

No installer. Sudo is optional — it can launch as administrator directly. It does not modify game files or skip owning the game.

64-bit Windows and .NET Framework 4.8. Not affiliated with Ubisoft. [Feedback](https://github.com/TROJAN29/trials-rising-launcher/issues)
